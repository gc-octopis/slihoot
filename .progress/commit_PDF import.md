# PDF 匯入功能以及介面優化

## Summary

- 新增活動編輯頁的 PDF 匯入流程，匯入後會將 PDF 頁面加入活動流程時間軸。
- 支援移除已匯入 PDF，會同步移除對應的 PDF 頁面時間軸項目與上傳檔案。
- 修正刪除 PDF 後重新匯入不同 PDF 時縮圖仍顯示舊檔的快取問題。
- 優化活動編輯頁與題目編輯介面，提升版面清晰度與操作效率。

## Details

- 新活動可先建立暫存資料以支援直接匯入 PDF 或新增題目；若未儲存返回列表，暫存活動不會保留。
- 題目時間軸支援 PDF 頁與題目混合排序，題目卡片可整張拖曳調整順序。
- 兩張卡片之間與最後一張卡片後方可用浮出加號插入新題目。
- 題目卡片改用題型 icon 與不同底色區分題目類型。
- 題目編輯區改為大型題目輸入區與水平設定工具列。
